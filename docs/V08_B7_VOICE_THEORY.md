## Spoken syllable variety (vocal-tract engine)
1. Per-planet vowel inventory: 3/5/7/9 vowels spread across formant space, each nudged +/-10-15% per planet; optional long/nasal/rounded-front vowels and diphthongs.
2. Consonants = place (lips..glottis) x manner (stop, nasal, fricative, glide, trill, tap, affricate) x voicing, built from constriction position/tightness + noise + voicing.
3. Common sounds everywhere (stops, nasals, a/i/u); rare ones (clicks, ejectives, trills, retroflex) at low probability; uneven phoneme frequencies.
4. Syllable shapes per planet: CV always, plus some of V/CVC/CCV/CVCC; sonority rises toward the vowel; per-planet limits on syllable-final consonants.
5. Stress or tone per planet (fixed first / penult / last, weight-based, or 2-4 tones). Stressed = louder, longer, higher; unstressed vowels relax toward schwa. Rhythm type: syllable-, stress- or mora-timed.
6. Speech intonation: downdrift, final lengthening, greetings rise, replies fall. Speech, not notes.
7. Coarticulation: consonant transitions 20-60 ms, vowel transitions 80-200 ms; never jump.
8. Speaking voice from body genes (tract length, pitch, breathiness, wobble, rate); separate from the instrument.
9. Names 1-4 syllables (mostly 2-3), no immediate repeats, offensive-word filter.
10. Same-system planets: parent inventory + 2-4 sound changes (p>f, k>ch before i, vowel shifts, final-consonant loss).
11. Culture accents as weights only; never imitate real spoken languages.
12. Cost: tables once per world, a few phoneme ids per ohm at birth, synthesis only when audible.
